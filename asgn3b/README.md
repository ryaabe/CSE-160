# Assignment 3b

## Project Overview

This is an extension of the Assignment 3 project, Blocky World, specifically tailored for the blocky world contest.

This project was heavily inspired by minecraft ARG videos, and I tried to mimic that bait & switch surprise factor that many of these videos have.
