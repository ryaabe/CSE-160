## Assignment 4: Lighting

Ryan Abe

### Project Overview

All features are added required from the assignment page. I chose to use the blocky animal assignment as the base. Move the camera through space using WASD. Move up and down using ctrl/shift. Look around using the mouse. 

You can change the colors of the light and spotlight using the various sliders, as well as the positions.

The spotlight is always angled towards the cat, no matter where it's position is.
